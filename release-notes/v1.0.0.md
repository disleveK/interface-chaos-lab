# Interface Chaos Lab v1.0.0

The first public release turns frontend resilience testing into a deterministic, replayable storm.

## Included

- 22 scenarios covering accessibility, mobile, localization, data, network, authentication, and persistence
- Seeded Disaster Roulette plans
- Evidence-first severity classification
- A 0–100 survival score with coverage reporting
- Audit, focused-storm, fix-critical, and prove-the-fix modes
- A real OncoSys AI case study
- Automated validation on pushes and pull requests

## Install

Clone or copy the repository into your skills directory, then use:

```text
@interface-chaos-lab unleash
```
